Neural Network Predictive System

Introduction

This project demonstrates a predictive system using a Neural Network in Python.

Dataset

Fashion MNIST Dataset.

Technologies Used

- Python
- TensorFlow
- NumPy
- Matplotlib

Features

- Loads the Fashion MNIST dataset.
- Trains a Neural Network model.
- Predicts clothing categories.
- Displays model accuracy.
- Shows predicted and actual results.

Output

The system predicts clothing images into 10 categories, such as T-shirt, Trouser, Dress, Bag, Sneaker and Ankle Boot.

Conclusion

This project demonstrates how Neural Networks are used for image classification and prediction.
